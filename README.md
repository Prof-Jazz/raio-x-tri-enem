# Raio-X TRI · Enem 2021 a 2025

Análise dos microdados do Enem de 2021 a 2025 (INEP), caderno amarelo, aplicação regular, PPL, Digital (2021) e Belém (2025): alunos com o mesmo número de acertos e notas diferentes (coerência pedagógica), dificuldade dos itens (parâmetro b), discriminação (parâmetro a), a virada do parâmetro a, quem errou só uma questão e o preço de cada erro.

- `index.html`: o relatório interativo (abre no navegador)
- `raio-x-tri-enem-2021-a-2025.pdf`: o mesmo relatório em PDF

Fonte: INEP, Microdados do Enem 2025.
